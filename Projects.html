Triton Lost and Found

Java, Spring Boot, Flyway, PostgreSQL, Docker

July 2026 - Present

Triton Lost and Found is a web application designed to help UC San Diego students report lost and found items and submit claims to recover appropiate belongings. Built with Java, Spring Boot, and PostgreSQL, the project uses Spring Data JPA for database operations, Flyway for database migrations, and DTOs to validate incoming requests and maintain clean REST API design. I am also using Docker Compose to containerize the application's environment and database.

UCSDelivery

TypeScript, Express, MariaDB, Docker

November 2025 - January 2026

UCSDelivery is a campus delivery app for UCSD students where they can order things from their local on campus market. A discord bot then posts each order to. deliverer's channel. When a deliverer accepts an order, the bot opens a private channel with the order details. The deliverer uploads a photo as proof of delivery, and the order is then marked complete. The frontend is built with React, and then the backend was built with Node.js/Express sserver with a MariaDB database which stores useres, items, and orders. The web app is also containerize with docker compose.
